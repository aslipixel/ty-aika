# Чертёж 3D — приложение для Android

Распознаёт план этажа с фото или скана, строит 3D-модель и объясняет обозначения строительных чертежей (ГОСТ СПДС).
Работает без интернета: three.js и шрифты лежат внутри приложения.

Сборка: GitHub Actions → «Build Чертёж 3D Android» → Run workflow.
Скачать свежий APK: https://github.com/aslipixel/ty-aika/releases/download/chertezh3d-android/Chertezh3D.apk
